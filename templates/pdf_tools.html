How this tool treats your document

  • Nothing is uploaded. The file is read with the browser's File API and written back out as a Blob. There is no upload endpoint, no storage, and no logging of file contents.
  • Pages are copied, never redrawn. Content streams come across byte for byte — verified with SHA-256 against real documents. Nothing is rasterised.
  • Nothing is flattened. Annotations, form fields and layers stay live objects, and the form-field appearance regeneration that would silently restyle a filled form is switched off.
  • Rotation changes a number, not a picture. Only the page's rotation attribute is altered.
  • Anything that cannot be preserved is named. Every result lists what was carried across, what had to be rebuilt, and what could not come along.
  • Encrypted PDFs are refused, not unlocked. This tool does not remove PDF passwords or permissions.
